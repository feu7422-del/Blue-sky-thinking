# 桌面图标开关 · 使用说明

一键显示 / 隐藏桌面上所有图标的小工具。

---

## 一、安装

双击 **`桌面图标开关_安装包.exe`**，会弹出一个安装窗口：

1. **安装位置** —— 默认 `%LOCALAPPDATA%\Programs\桌面图标开关`，想换就点「浏览…」。
   装在你自己的目录里，**不需要管理员权限**，也不会弹 UAC。
   如果检测到你已经装过，会自动填上原来的位置（重新安装 = 覆盖更新）。
2. **三个勾选项** —— 桌面快捷方式 / 开始菜单快捷方式 / 开机自动启动，默认全勾。
3. 点「开始安装」，装完问你「现在就用一下吗？」，选「是」就直接跑起来。

装完桌面会多一个图标：

```
桌面图标开关.lnk  →  D:\...\DesktopIconSwitcher.exe
```

---

## 二、怎么切换显示 / 隐藏

有三种方式，随便用哪种：

| 方式 | 操作 |
|---|---|
| **桌面图标** | **双击**桌面上的「桌面图标开关」 |
| **右下角托盘** | 开机自启开着的话，托盘有一个小图标，**单击**它 |
| **设置窗口** | 点「立即切换显示 / 隐藏」按钮 |

> 为什么桌面那个要双击？这是 Windows 自己的规矩：桌面图标默认就是双击打开。
